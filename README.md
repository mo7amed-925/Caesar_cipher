# 🔐 Caesar Cipher Desktop App

![Java](https://img.shields.io/badge/Java-17-orange)
![JavaFX](https://img.shields.io/badge/JavaFX-UI-blue)
![Status](https://img.shields.io/badge/status-active-success)

A modern desktop application that encrypts and decrypts text using the Caesar Cipher algorithm, built with JavaFX and a clean HTML/CSS interface.

---

## 🚀 Features

- 🔒 Encrypt text (shift = 3)
- 🔓 Decrypt text instantly
- 🎨 Modern responsive UI
- 🌐 External profile links (LinkedIn & GitHub)
- ⚡ Lightweight & fast

---

## 🛠️ Tech Stack

- Java (JavaFX)
- HTML / CSS / JavaScript
- WebView (UI rendering)
